# Konfigurasi & Administrasi Server CentOS 7

## 📌 Deskripsi Proyek
Repositori ini berisi dokumentasi dan laporan hasil praktikum mandiri mengenai administrasi sistem operasi server berbasis Linux (**CentOS 7**). Proyek ini berfokus pada pemahaman dasar pengelolaan server melalui *Command Line Interface* (CLI) di dalam lingkungan mesin virtual, yang mencakup pengaturan pengguna, hak akses keamanan, hingga konfigurasi jaringan dasar.

---

## 🛠️ Alat dan Sistem yang Digunakan
- Sistem Operasi: CentOS 7
- Lingkungan Virtualisasi: Oracle VirtualBox
- Antarmuka: Terminal Linux (CLI)
- Pengendali Versi: Git & GitHub

---

## 📋 Langkah-Langkah Pengerjaan
Berikut adalah tahapan konfigurasi yang saya lakukan selama praktikum:

### 1. Pengelolaan Pengguna (User Management)
- Membuat akun pengguna baru pada sistem menggunakan perintah dasar manajemen *user*.
- Menetapkan serta memperbarui kata sandi guna menjaga keamanan akses awal sistem.

### 2. Pengaturan Hak Akses Administratif (Wheel Group)
- Memasukkan akun pengguna ke dalam kelompok **`wheel`**.
- Mengatur agar pengguna tersebut memiliki hak akses untuk menjalankan perintah istimewa (`sudo`), sehingga pengelolaan sistem dapat dilakukan dengan lebih aman tanpa harus selalu masuk sebagai akun `root`.

### 3. Konfigurasi Jaringan dan Pengaturan DNS
- Menyesuaikan parameter jaringan pada sistem agar terhubung dengan baik.
- Mengatur konfigurasi *DNS resolver* agar server mampu menerjemahkan alamat jaringan dan berkomunikasi dengan lancar.

---

## 📈 Hasil dan Pencapaian
- Berhasil menerapkan dasar-dasar manajemen hak akses pengguna yang aman dan terstruktur pada peladen (*server*).
- Memastikan konfigurasi jaringan serta DNS pada mesin virtual CentOS 7 berjalan dengan stabil.
- Menyusun dokumentasi kerja nyata dalam bentuk rekaman video praktikum.
